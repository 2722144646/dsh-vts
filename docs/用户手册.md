# 用户手册

> 这份文档只讲**怎么把它跑起来、怎么用**。不涉及任何个人数据。
> 功能清单和各工具的用途见 [功能说明](功能说明.md)。

---

## 0. 它是什么

把 dsh 变成一个能持续在线的 Live2D 数字人：

```text
你说的话（或 dsh 的回复）
  → 本地 TTS 出声
  → 同时驱动 VTube Studio 里模型的嘴型、表情、头部、待机动作
```

需要一个已经装好的 **VTube Studio**（Steam 版即可）和一个 **Live2D 模型**。

## 1. 准备

| 需要 | 说明 |
|---|---|
| Windows | 目前只在 Windows 上验证过 |
| Python 3.11+ | 建议用独立 venv |
| VTube Studio | 开着，装好模型 |
| VTS 的 API | VTS 设置里打开 API（默认端口 8001，会自动探测 8001–8010） |
| 一个 Live2D 模型 | 你自己的或买的，授权自己负责 |

## 2. 安装

```powershell
cd <项目目录>
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```

这一步会建 `.venv` 并装依赖，不动系统 Python。

## 3. 启动（顺序别乱）

```text
① 打开 VTube Studio，载入模型，确认 API 已开（端口在 VTS 设置里看）
② 启动桥接：python -m dsh_vts_avatar --config config.toml serve
③ 在 dsh 里启用 dsh-vts-avatar 插件
```

插件会自动连 `ws://127.0.0.1:8765`（桥接的地址）。

检查是否连上：

```powershell
python -m dsh_vts_avatar --config config.toml probe
```

`probe` 会打印当前模型的 ID、参数数量，并生成该模型的参数档案。

## 4. 日常使用

- **说话**：正常和 dsh 对话即可，桥接会把文字送进 TTS 并驱动嘴型。
- **手动让她说一句**：`vts_avatar_say` 工具。
- **看她的样子**：`vts_avatar_look`（NDI 抓帧，可以一次抓好几帧看动作）。
- **表情**：`vts_avatar_feel` 自述情绪，或者 `vts_avatar_emote` 直接指定预设。
- **待机动作**：桥接会自动播放；批次过期时会提示模型重写。

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 插件连不上 | 桥接没启动，或端口不是 8765；先跑 `probe` 看 |
| VTS 报错 100 / 认证失败 | 关掉 VTS 里的旧插件授权，重启桥接重新认证 |
| 有声音但模型不动 | 模型没载入 / API 没开 / 端口不对 |
| 抓不到画面 | 没装 NDI 或 VTS 的 NDI 输出没开；`vts_avatar_look` 会报状态 |
| 嘴型很生硬 | 见 [功能说明](功能说明.md) 里的「嘴部通道」一节 |

## 6. 数据放在哪

```text
data/            运行数据（对话记录、情绪事件、模型档案、抓帧）
models/          TTS / RVC 模型文件（体积大，需要自己下载）
config.toml      配置
```

`data/` 全部是**本机数据**，默认不进版本库、不上传。想清空就整个删掉，程序会重新建。

## 7. 卸载

删掉项目目录即可。插件在 dsh 里禁用；VTS 里撤销该插件的授权。
