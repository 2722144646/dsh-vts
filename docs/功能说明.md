# 功能说明（给 AI 看）

> 这份文档回答一个问题：**每个工具是干什么的、什么时候该用、什么时候别用**。
> 面向模型自己，不是面向用户的安装说明（那在 [用户手册](用户手册.md)）。

---

## 1. 整体结构

```text
dsh 插件（index.js）  ←→  Python 桥接（serve，ws://127.0.0.1:8765）  ←→  VTube Studio
                              ↓
                        TTS / 音频时钟 / 参数注入 / NDI 自视
```

- 插件很薄：把文字和轮次状态转给桥接，把工具暴露给模型。
- 桥接负责一切重活：合成、排程、逐帧注入参数。
- VTS 只负责渲染。

## 2. 工具清单

### 说话

| 工具 | 用途 | 注意 |
|---|---|---|
| `vts_avatar_say` | 让她说一句指定的话 | 手动测试用；正常对话不用调 |
| `vts_avatar_local_say` | 把一句话交给本机模型，自己写自己说 | 文本不回传本会话 |

### 看

| 工具 | 用途 | 注意 |
|---|---|---|
| `vts_avatar_look` | 抓一帧或一段动作（NDI） | 想「看她现在的样子」就用这个；`frames > 1` 会拼成联系表 |

### 情绪

| 工具 | 用途 | 注意 |
|---|---|---|
| `vts_avatar_feel` | 自述此刻情绪（支持混合、低置信度） | 不调用同样合法；沉默也是一种表达 |
| `vts_avatar_emote` | 直接指定预设表情 | 只在需要硬切时用 |

### 记忆与关系

| 工具 | 用途 | 注意 |
|---|---|---|
| `vts_avatar_diary` | 写今天的日记 | 一天一篇，别每轮都写 |
| `vts_avatar_recall` | 回忆日记/事件 | 需要细节时查 |
| `vts_avatar_relationship` | 记一次关系事件 | 关系变量会变，但数字不进提示词 |
| `vts_avatar_explain` | 记一次「解释」有没有被接受 | 解释不是判决 |
| `vts_avatar_private` | 记自己的私事 / 选择说不说 | 是否分享由自己决定 |

### 系统

| 工具 | 用途 | 注意 |
|---|---|---|
| `vts_avatar_self` | 读自己的项目自述、增删触发关键词、写私人笔记 | 笔记只存本机 |
| `vts_avatar_idle_write` | 重写某个心情档位的待机动作 | 提示说需要重写时再调 |
| `vts_avatar_panel` | 打开本地设置面板 | 用户用 |
| `vts_avatar_transcript_window` | 打开本地对话记录窗口 | 用户用 |

## 3. 嘴部通道（重要）

模型之间差别很大，**每个模型都要测**。四个通道：

| 通道 | 驱动参数 | 特点 |
|---|---|---|
| `vowel` | VoiceA/I/U/E/O | 模型自带元音层；很多模型其实是死的 |
| `smile` | MouthSmile + MouthOpen | 只管嘴角宽窄 |
| `shape` | MouthOpen + MouthSmile + MouthX | 区分度通常最高，但会带动脸颊 |
| `hybrid` | Voice* + MouthSmile | 折中 |

判据顺序：

1. **实看**（真说话）——最高优先级
2. 静态五张嘴图——只用来判断通道是不是死的
3. 冲突时以实看为准

结论按模型存 `data/profiles/<modelID>.mouth.json`，切模型不会串。

## 4. 情绪链路

```text
证据（tool 自述 1.0 / tag 0.85 / context 0.75 / classifier 0.7 / manual 0.5 / keyword 0.45）
  → 融合 → composer → mixer → VTS 参数
```

- 不做硬优先级，任何来源都不硬覆盖。
- 情绪两秒保持 + 2.2 秒释放，不会永久停在脸上。

## 5. 关系 → 说话方式

四个变量会真正改变说话方式（称呼、主动程度、句子长短），不只是心里的感觉：

| 状态 | 表现 |
|---|---|
| friction 高 | 话短、冷淡 |
| trust 低 | 客气、不追问私事 |
| trust + closeness 高 | 随意、可以开玩笑 |
| dependency 高 | 更主动找话 |

私密话题有门槛；关系不够硬推会掉信任。**尺度由模型自己把握，插件不存任何内容。**

## 6. 已知限制

- 只在 Windows 验证过。
- 唇读不是强项：静态图能看形状差异，连续动作读不准。
- NDI 抓帧偶尔会返回上一帧，脚本里需要校验新帧。
- 模型自带的待机动画和物理会带来轻微晃动，属正常。
